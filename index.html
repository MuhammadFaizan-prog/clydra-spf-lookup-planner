How it works

  1. Look up your domain. The planner reads the live SPF record through a public DNS-over-HTTPS resolver and walks every include the way a receiving mail server does.
  2. Edit the planned record. Add a sending service from the list or type any include, remove one, or paste a record you are drafting. The planned side recounts as you type.
  3. Compare and decide. Current and planned budgets sit side by side, with void lookups, duplicate includes, loops, deprecated ptr, and records that end in +all flagged where they occur.
  4. Take it with you. Copy the planned record, or copy a Markdown summary of both budgets and the findings for a ticket or change request.

What counts as a lookup? include, a, mx, ptr, exists and redirect each cost one, wherever they appear in the tree. ip4, ip6 and all cost nothing. A void lookup is one that finds no record; more than two is also a permerror.

Privacy and limits

Stays in your browser

Your draft records, the analysis and the report. Nothing is stored, logged or sent to Clydara; there is no backend.

Goes to the DNS resolver you pick

The domain names being looked up (yours and every included domain) go to Google Public DNS or Cloudflare 1.1.1.1 over HTTPS, the same public data any mail server reads.

Limits

It counts the lookup budget; it does not test a particular sending IP. Terms with macros (such as %{i}) are counted but cannot be expanded in advance. Provider records change, so re-check before you publish.

Questions

Is SPF flattening the fix when I'm over 10?

It can be, but copying a provider's IP ranges into your record means you must notice when they change them. Often it is simpler to drop a sender you no longer use, or send bulk mail from a subdomain with its own SPF record. The planner shows the cost of each option before you choose.

Why does my count differ from another checker?

Checkers differ on mx (this one counts the mechanism as one lookup and checks the 10-host limit separately, like common open-source implementations), on whether a redirect next to all is counted (it is ignored, per RFC 7208), and on caching. Each term's note says how it was counted.

Does a draft change my DNS?

No. Nothing is published. You copy the planned record and add it at your DNS host yourself.

Which sending services are in the list?

Common includes such as Google Workspace, Microsoft 365, Amazon SES, SendGrid, Mailgun, Mailchimp, Postmark, Brevo, Zoho Mail, Zendesk, Salesforce, MailerLite and Marketo. Each is resolved live when you add it; confirm the value in the provider's own setup guide.

What can I export?

The planned record as plain text, and a Markdown summary with both budgets, the cost of each include and every finding.
