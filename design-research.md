# Design research (browser, 2026-10-16)

Patterns only; nothing copied. Pinterest (login wall) and Mobbin (no public search) were skipped; Behance searches returned only generic CRM dashboards.

| Reference | Pattern taken |
|---|---|
| [dmarcian SPF Surveyor](https://dmarcian.com/spf-survey/) | Number-led "N/10" budget; expandable include tree with per-node lookup badges |
| [Dribbble: Warmy DNS Records](https://dribbble.com/shots/25469146-Warmy-Dashboard-DNS-Records) | Single score beside a per-record status list |
| [Dribbble: Decision Tree Builder (SAY Design)](https://dribbble.com/shots/27296349-AI-Workflow-Automation-SaaS-Decision-Tree-Builder-UI-SAY-Des) | Tree that reads in order with numbered steps and inline add controls -> numbered evaluation order + add-sender chips |
| [Dribbble: Campaign Performance and Analytics Dashboard](https://dribbble.com/shots/27782318-Campaign-Performance-and-Analytics-Dashboard) | "X of Y" budget with three exact states (ok / near / over) instead of a gradient |
| [Dribbble: Infra.Email Warmup Analytics](https://dribbble.com/shots/27272525-Infra-Email-Per-Inbox-Warmup-Analytics-Dashboard) | Segmented composition bar -> where the lookups go; actionable alert rows -> findings |

Resulting identity: dark graphite instrument panel, a ten-cell gauge (the limit is small and exact), lime accent, amber "close to the limit", coral "over", monospace numerals. Deliberately unlike the light cron/CSP/robots tools.
